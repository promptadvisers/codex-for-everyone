## State definitions
- CONFIGURED: saved schedule inspected; no completed scheduler result yet.
- RUNNING: actual scheduler execution is queued or running; not complete.
- VERIFIED: actual scheduler execution completed, its output passed the checks, and intended recurring settings were restored.
- BLOCKED: missing setup, failed skill, failed run or unresolved evidence; record the specific error and next action.

A prepared checkpoint, normal chat run or saved configuration does not verify an automation. Record partial progress honestly.
