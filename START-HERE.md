# OpenAI Codex for Everyone — course kit

## The practice situation

You help coordinate a project to improve employee onboarding. Every Monday, the VP of Operations wants a short update: what changed, what needs a decision, and what happens next.

**Northstar** is the fictional project we use together. Its meeting notes, team messages and budget export contain inconsistencies. Ask Codex to produce the update, then check its claims against those original files. We call the document the **Monday Brief**; that is the course’s name for a weekly project update, not a Codex feature.

- **Lab 1:** draft the update from the Northstar files and check a claim
- **Lab 2:** inspect a separate, deliberately flawed sample and verify the corrections
- **Lab 3:** switch to the personal project and create a reusable skill for a task from your work
- **Scheduling:** test that personal skill through a scheduled run after its manual check passes

The class uses fixed scenario dates so everyone can examine the same evidence. Your real recurring task needs its own reporting rule and refreshed inputs.

O’Reilly, 16 October 2026. Revised 15 October 2026. All practice inputs are fictional.

1. Extract this ZIP. Before Lab 1, open the extracted 00-start folder as a local Codex project.
2. Open course-guide/START-HERE.md inside that project beside the chat. The guide, prompts, cards and portable skill are all available there.
3. Pass the readiness gate in course-guide/RUNBOOK.md. Use the full prompts with matching lab names.
4. At Lab 3, open the separate 01-my-recurring-task folder as a new project. Read its neutral instructions and choose ONE filled task example and input folder. Keep your Northstar work intact.
5. Use each project's course-guide/COMPLETION-CARD.md to record evidence.

## Recovery map
Northstar checkpoints 01, 02 and 03 are self-contained working projects with their own course-guide. Open the specific one as a new project; prepared results are references, not completed learner runs. Checkpoint 04 contains only the schedule recipe; do not open it as a working project or treat it as a receipt. Your personal task has a neutral skill template in its guide; adapt that rather than reusing Northstar unchanged.

No skill has been installed and no schedule has been created by this package. Local scheduled runs need the computer on, app running, accessible inputs and suitable permissions. Verify a real scheduler execution.
