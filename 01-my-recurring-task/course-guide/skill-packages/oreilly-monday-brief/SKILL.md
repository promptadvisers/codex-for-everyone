# Weekly project brief

1. Identify the project source folder, audience, reporting period and as-of date. Prefer the current request. PROJECT-README.md defines the course fixture only. Ask if the period is missing.
2. Read relevant sources and preserve them. Report missing current-period evidence instead of presenting old evidence as new.
3. Resolve dates using the latest explicit decision and name the superseded source.
4. Keep suggested owners unconfirmed until evidence records acceptance or assignment.
5. Count identical budget rows once per item_id and disclose duplicates. Flag conflicting amounts for the same ID.
6. Use templates/weekly-brief.md beside this skill. Cite filenames and dates or row IDs. Separate evidence from implications.
7. Write output/brief-YYYY-MM-DD.md using the brief date. Show the path, checks and unresolved questions.
8. Do not send the brief or create a schedule merely because the skill ran.

Use checks/cases.md after a revision.
