# Northstar project guidance

Audience: VP of Operations. Write deliverables under output/.

- Use the requested reporting period; PROJECT-README.md supplies the classroom fixture period. Ask if a real task has none.
- Cite factual claims with filenames and dates or row IDs.
- Resolve dates using the latest explicit decision; explain what it supersedes.
- Label suggested but unaccepted owners as unconfirmed.
- Count identical budget item IDs once and report duplicates. Flag conflicting amounts instead of guessing.
- Separate evidence from implications and report missing inputs.
- Preserve source files.
