# Troubleshooting

- Wrong folder: open 00-start or a checkpoint as project root; start a fresh chat.
- Missing output: inspect run state and output path; use a prepared checkpoint to continue.
- Wrong fact: open the source and request a targeted correction.
- Skill absent: verify location/name, follow INSTALL-SKILL.md, restart if needed.
- Connector unavailable: use the labeled source export and explain the limitation.
- Schedule fails: inspect the actual error, model, permissions, inputs and computer/app state.
- Usage or corporate restrictions: record the exact blocker. Do not claim an unrun task is complete.
- Parallel edits: give each chat ownership of a different output.
