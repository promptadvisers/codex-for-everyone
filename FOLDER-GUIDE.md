# What is in the learner kit?

## Start with 00-start for Labs 1 and 2

- `PROJECT-README.md`: the fictional Northstar onboarding situation, audience and fixed reporting dates
- `course-guide/`: exact prompts, lab steps, task cards, skill setup and recovery help
- `sources/`: original meeting notes, team messages, project status and budget CSV; preserve these files
- `templates/`: the structure for the weekly project brief
- `prepared-review/flawed-brief.md`: the deliberately flawed sample used in Lab 2
- `output/`: the new files Codex creates during the exercise

## Switch to 01-my-recurring-task for Lab 3

- `PROJECT-README.md` and `AGENTS.md`: neutral project setup and guidance
- `course-guide/task-examples/`: three filled task cards to choose from or adapt
- `course-guide/TASK-CARD.md`: your selected task, audience, inputs and quality check
- `practice-inputs/`: fictional weekly-update, meeting-actions and document-check packs; choose one
- `output/`: the result of your own tested skill

## Other folders

- `checkpoints/`: prepared recovery examples; use if a lab stalls and label them as prepared
- `skill-packages/`: the Northstar example skill and supporting files
- `resources/`: reference links, app tour and troubleshooting

The project folders contain their own course guide so the instructions remain available when that folder is opened alone. `.md` files are ordinary text documents written in Markdown. Download and extract the whole kit before using it locally; viewing a Drive folder alone does not attach it as a local Codex project.
